宵宫 Q 版桌宠

启动：
双击 YoimiyaDesktopPet.exe。首次运行如遇 Windows 提示，选择“更多信息”再选择“仍要运行”。

基础操作：
- 单击头饰、脸、挂饰、衣服、手部或身体：不同互动
- 连续点击三次：快速点击专属反应
- 双击角色：随机行动
- 拖动角色：移动位置
- 鼠标滚轮：调整大小
- 右键角色：控制中心、烟花小游戏和全部功能

状态：
桌宠会根据精力、心情、饱腹和专注度选择行动，也会根据时间、电量与全屏状态调整表现。

成长：
右键可以给点心或喝水，也可以在控制中心查看等级、好感度、清洁、健康与库存。

智能聊天：
右键选择“填入deepseekAPI KEY”，保存后选择“聊天”即可对话。
API Key 只加密保存在本机，聊天需要联网。

动作：
学习和日常动作会随机使用两套不同姿态，吃东西、喝水和打盹都有独立图片与道具。

喂食：
右键选择“喂食”打开小铺，可以购买食物、甜点、饮品和小物。购买后选择“给宵宫使用”会提升对应数值。

稳定性：
程序会自动记录启动和异常日志，重复启动不会产生多个冲突实例。

自定义台词：
打开控制中心，选择“编辑台词”。保存 JSON 文件后，右键选择“重新载入台词”。

设置保存在程序目录的 data 文件夹中。程序不需要联网。
